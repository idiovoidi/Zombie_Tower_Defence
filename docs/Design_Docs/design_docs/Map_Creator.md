Let's build a custom map creator where players can create their own style paths and save the level and share with others. This will allow a community driven approach to level and map balance in the future. For the immediate future we need to construct tools that allow for custom map tile placement, control of zombie hordes per wave and the saving of these maps. The code should have as little future maintenance as possible whilst functioning as a feature. This feature is nice to have but it's not worth spaghetti code in the pursuit of achieving this functionality.
